# FreeProxy

Free, open-source Minecraft: Bedrock proxy with fly, speed, jetpack, night vision and more.
Works with Realms (RakNet and NetherNet) and normal servers. Made by hihellohejo.

- **iPhone (sideload):** download `FreeProxy.ipa` from Releases, sign/sideload it, open it, tap Start,
  then in Minecraft add server `127.0.0.1` port `19133`. Keep FreeProxy open in the background.
- **Android (Termux):** `./freeproxy`, then join the printed IP on port 19132 from any device on the same Wi-Fi.

Type `.help` in Minecraft chat for commands. Commands never reach the server.

Minecraft version: 1.26.60 (must match gophertunnel's protocol).
